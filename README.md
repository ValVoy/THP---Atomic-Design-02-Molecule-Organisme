# 🚀 THP Week 6 - Day 1: Atomic Design & UI Kits

This repository contains two front-end projects focusing on **Atomic Design** principles. The goal is to build reusable components (Atoms, Molecules, and Organisms) to create consistent user interfaces.

## 📁 Project 1: Custom UI Kit (No Framework)
A UI Kit built from scratch using pure CSS. 
- **Theme:** ClimbLink (Social network for climbers).
- **Constraints:** No Bootstrap allowed.
- **Key features:** Custom buttons, typography scales, form inputs, and basic cards.

## 🏗️ Project 2: Molecules & Organisms (Bootstrap/Bootswatch)
Advanced components designed for an "Eventbrite" clone.
- **Theme:** Eventbrite (using Bootswatch 'Flatly').
- **Key features:** Navigation bars, complex cards, authentication forms, and comment sections.
- **Architecture:** Each organism is separated into its own HTML file for better modularity.

## 🛠️ Installation
No installation required. These are static HTML/CSS files.
1. Clone the repository.
2. Open any `.html` file in your favorite browser.

## 📝 Commit Convention
Follows the standard: `type: description` (e.g., `feat: add card molecule`).
